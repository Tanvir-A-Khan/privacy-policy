Privacy Policy

Tasbeeh Noor

Last updated 2026-08-18

Tasbeeh Noor does not collect, store, or transmit any personal data.

What the app does

  • Tasbeeh Noor has no user accounts and requires no sign-in.
  • All counts, settings, and history are stored locally on your device only. This data never leaves your device.
  • The app contains no advertising and no third-party analytics or tracking libraries of any kind.
  • Uninstalling the app permanently deletes all of its data, since nothing is stored anywhere else.

About the internet permission

The app's Android package declares the INTERNET permission because it is required by the React Native runtime the app is built on, not because the app uses it. Tasbeeh Noor makes no network requests: there is no server, no API, and no code path anywhere in the app that sends or receives data over a network connection.

Changes to this policy

If a future version of Tasbeeh Noor adds a feature that changes any of the above — for example, cloud backup or crash reporting — this page will be updated first, and the change will be reflected here before it ships.

Contact

You can reach the developer through this app's listing on the Google Play Store.
